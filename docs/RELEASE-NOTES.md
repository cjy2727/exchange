## 환율 계산기 다운로드 및 실행

**Windows 10·11의 64비트(x64) PC용입니다.** 별도 설치 과정 없이 실행할 수 있으며, 환율 조회에는 인터넷 연결이 필요합니다.

1. 이 페이지 아래쪽의 **Assets**를 펼치고 **`ExchangeStudio-Windows.zip`**을 다운로드하세요.
2. 다운로드한 ZIP을 마우스 오른쪽 버튼으로 클릭하고 **모두 압축 풀기 → 압축 풀기**를 선택하세요.
3. 압축을 푼 폴더 안의 **ExchangeStudio** 폴더를 열고 **`ExchangeStudio.exe`**를 더블클릭하세요. 확장자가 숨겨져 있으면 **ExchangeStudio**로 보일 수 있습니다.
4. 브라우저에 계산기가 나타납니다. 날짜를 선택해 **환율 조회**를 누르고, 통화·금액·우대율을 입력해 계산하세요.
5. 사용 후에는 화면 위쪽의 **프로그램 종료**를 누르세요. 브라우저 창만 닫으면 프로그램은 계속 실행됩니다.

**`Source code (zip)`은 실행파일이 없는 개발용 소스입니다.** 반드시 `ExchangeStudio-Windows.zip`을 선택하세요. `SHA256SUMS.txt`는 파일 확인용이며 실행할 때는 필요하지 않습니다.

압축파일 안에서 바로 실행하지 말고, 압축을 먼저 풀어 주세요. EXE 옆의 **`_internal` 폴더도 함께 보관**하세요.

새 버전으로 바꿀 때는 프로그램을 종료하고 새 ZIP을 새 폴더에 풀어 실행하세요. 같은 Windows 사용자 계정에서는 저장한 기록과 설정이 유지됩니다.

자세한 사용 방법은 ZIP 안의 **README.txt**에서 확인할 수 있습니다.
