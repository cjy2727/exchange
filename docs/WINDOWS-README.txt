Exchange Studio — Windows 10/11 x64

[1. 처음 실행하기]

① 다운로드한 ExchangeStudio-Windows.zip을 마우스 오른쪽 버튼으로 클릭하고
   '모두 압축 풀기 → 압축 풀기'를 누르세요.
② 압축을 푼 폴더 안의 ExchangeStudio 폴더를 여세요.
③ ExchangeStudio.exe를 더블클릭하세요.
   확장자가 숨겨져 있으면 ExchangeStudio로 보일 수 있습니다.
④ 인터넷 브라우저가 열리면서 환율 계산기가 나타납니다.

폴더 안에는 다음 파일이 함께 있어야 합니다.
  ExchangeStudio.exe  ← 실행할 파일
  _internal           ← 실행에 필요한 폴더
  README.txt          ← 지금 읽고 있는 안내문

압축파일 안에서 바로 실행하지 마세요.
EXE만 옮기거나 _internal 폴더를 삭제하지 마세요.
위치를 바꾸려면 ExchangeStudio 폴더 전체를 옮기세요.

[2. 환율 계산하기]

① 조회할 날짜를 선택하고 '환율 조회'를 누릅니다.
② 통화·거래 유형·외화 금액·우대율을 입력합니다.
③ '원화 비용 계산하기'를 누릅니다.
④ 결과를 보관하려면 '계산 기록 저장'을 누릅니다.
⑤ 저장한 기록을 엑셀로 받으려면 '엑셀 다운로드'를 누릅니다.

[3. 종료하기]

화면 위쪽의 '프로그램 종료'를 누르고 확인을 선택하세요.
종료 안내가 나오면 브라우저 탭을 닫으세요.
브라우저 창만 닫으면 프로그램은 계속 실행됩니다.
화면을 다시 열려면 ExchangeStudio.exe를 다시 실행하세요.

[4. 새 버전으로 바꾸기]

프로그램을 종료하고 아래 페이지에서 새 버전을 다운로드하세요.
https://github.com/cjy2727/exchange/releases/latest

Assets를 펼쳐 ExchangeStudio-Windows.zip을 선택하세요.
Source code (zip)은 실행파일이 없는 개발용 소스입니다.
새 ZIP을 새 폴더에 압축 해제하고 실행하세요.
같은 Windows 사용자 계정에서는 기존 기록과 설정이 유지됩니다.

[5. 실행이 잘 안 될 때]

- EXE가 없고 app.py 같은 파일만 보이면 소스코드를 받은 상태입니다.
  다운로드 페이지에서 ExchangeStudio-Windows.zip을 받으세요.
- 환율 조회가 안 되면 인터넷 연결을 확인하고 잠시 후 다시 시도하세요.
  계속 실패하면 화면에 나온 오류 문구를 담당자에게 알려 주세요.

[6. 기록 백업하기 / 프로그램 지우기]

먼저 프로그램을 종료하세요.
키보드의 Windows 키와 R을 함께 누르고 아래 경로를 입력한 뒤 확인하세요.
%LOCALAPPDATA%\ExchangeStudio

기록 백업: exchange.sqlite3 파일을 다른 폴더에 복사해 보관하세요.
프로그램 제거: 압축을 풀었던 ExchangeStudio 프로그램 폴더를 삭제하세요.
저장 기록도 모두 지우려면 위 데이터 폴더를 별도로 삭제하세요.
데이터 폴더를 삭제하면 계산 기록과 우대율 설정이 함께 삭제됩니다.

[상세 정보 / 개발자 참고]

Python 설치나 관리자 권한은 필요하지 않습니다.
환율 조회에는 인터넷과 Windows 기본 curl.exe가 필요합니다.
8080 포트 사용 중에는 사용 가능한 다른 포트를 자동으로 선택합니다.

기록과 설정: %LOCALAPPDATA%\ExchangeStudio\exchange.sqlite3
진단 로그: %LOCALAPPDATA%\ExchangeStudio\app.log
백업: 프로그램 종료 후 exchange.sqlite3를 복사하세요.
업데이트: 프로그램 종료 후 새 ZIP을 별도 폴더에 풀어 실행하세요.
기록은 프로그램 폴더 외부에 보관되므로 그대로 유지됩니다.
제거: 프로그램 종료 후 압축 해제한 폴더를 삭제하세요.
저장 기록까지 지우려면 위 데이터 폴더도 별도로 삭제하세요.

기존 소스 버전 기록 가져오기:
두 프로그램을 모두 종료하고 기존 data\exchange.sqlite3를 위 데이터 폴더로
복사하세요. 기존 배포판 기록이 있다면 먼저 백업하세요. 병합은 지원하지 않습니다.

이 배포판은 코드 서명되지 않았습니다. Windows 보안 확인이 표시될 수 있습니다.
다운로드 출처와 함께 제공된 SHA256SUMS.txt를 확인하세요.
출처: https://github.com/cjy2727/exchange/releases

하나은행 공식 프로그램이 아닌 개인용 계산 도구입니다.
실제 환전 및 송금은 실행하지 않습니다.
